0. อ่านผลนี้อย่างไร

สิ่งที่ผลวิเคราะห์ยืนยันได้

  • โครงสร้างไฟล์และจำนวนข้อมูลตรงกับ metadata ทางการ
  • สัดส่วน class เปลี่ยนไปตาม batch อย่างชัดเจน
  • feature distribution ของหลาย batch ต่างจาก Batch 1
  • แม้ควบคุมให้เป็น class เดียวกันแล้ว ยังพบ class-conditional drift
  • protocol และ sample IDs สามารถสร้างซ้ำจาก seed เดิมได้

สิ่งที่ผลนี้ยังยืนยันไม่ได้

  • ยังสรุปไม่ได้ว่าโมเดลใดแม่นที่สุด เพราะยังไม่ได้ train classifier
  • MMD ที่สูงไม่ได้บอกสาเหตุว่าเกิดจาก sensor aging, สภาพแวดล้อม หรือปัจจัยใดโดยตรง
  • ยังไม่มี permutation test หรือ confidence interval จึงไม่ควรเรียกค่า MMD ว่า “มีนัยสำคัญ”
  • PCA เป็นภาพฉาย 2 มิติ ไม่ได้เก็บรายละเอียดครบทั้ง 128 มิติ
  • Leakage audit ที่ผ่าน ไม่รับประกันว่างานโมเดลในอนาคตจะไม่ leak หากนำ target labels ไป tune
แนวคิดสำคัญ: ในรายงานนี้ batch หมายถึงกลุ่มข้อมูลที่เก็บต่างช่วงเวลา จึงทำหน้าที่เหมือนคนละ domain ไม่ใช่ mini-batch ที่สุ่มใช้ระหว่างการ train การแบ่ง train/test แบบสุ่มข้ามทุก batch อาจทำให้ผลดูดีกว่าการใช้งานจริงในอนาคต

1. Dataset schema

ยืนยันกับ UCI official source — DOI: 10.24432/C5RP6W

ผลนี้บ่งบอกอะไร

แต่ละ sample คือการวัดการตอบสนองต่อก๊าซหนึ่งครั้ง มี feature 128 ค่า ซึ่งมาจาก 16 sensors × 8 features ต่อ sensor และมี label เป็นก๊าซ 6 ชนิด การที่ schema เป็น PASS หมายถึง parser อ่านไฟล์ได้ครบ 13,910 แถว, พบ feature 1–128 ครบทุกแถว, ไม่มี NaN/Infinity และพบ batch/class ตามจำนวนที่คาดไว้

ผล PASS นี้สำคัญเพราะลดความเสี่ยงที่ผล drift จะเกิดจากไฟล์ขาด คอลัมน์เลื่อน หรืออ่าน LIBSVM ผิดรูปแบบ อย่างไรก็ตาม PASS เป็นการยืนยันความสมบูรณ์เชิงโครงสร้าง ไม่ใช่การรับรองว่าข้อมูลสมดุลหรือไม่มี drift

2. Class count, missing class และ imbalance

ความหมายของตัวชี้วัด

  • Class proportion คือสัดส่วนของแต่ละก๊าซภายใน batch นั้น
  • Imbalance ratio = จำนวน class ใหญ่สุด ÷ class เล็กสุด ค่า 1 หมายถึงสมดุลพอดี ถ้ามี class count = 0 อัตราส่วนจะเป็น infinity
  • Normalized entropy อยู่ใกล้ 1 เมื่อสัดส่วนทุก class ใกล้เคียงกัน และลดลงเมื่อข้อมูลกระจุกอยู่บาง class
ข้อค้นพบหลัก: เมื่อรวมทุก batch อัตราส่วนสูงสุด/ต่ำสุดเท่ากับ 1.834:1 ซึ่งดูไม่รุนแรง แต่ค่านี้ซ่อนปัญหาระดับ batch ไว้ ตัวอย่างเช่น Batch 2 มี ratio 106.4:1 และ Batch 3–5 ไม่มี C6 (Toluene) เลย ในทางกลับกัน Batch 10 สมดุลพอดี 600 ตัวอย่างต่อ class
ผลกระทบต่อโมเดล: Accuracy รวมอาจถูกครอบงำโดย class ใหญ่ และใน Batch 3–5 ไม่สามารถประเมิน recall ของ Toluene ได้เลย ควรรายงาน macro-F1, balanced accuracy, per-class recall และ confusion matrix ควบคู่กับ accuracy เสมอ การรวมทุก batch แล้วดูเฉพาะ overall ratio ไม่เพียงพอ

3. Source-target class-prior mismatch

Class prior คืออะไร

Class prior คือโอกาสพบแต่ละ class ก่อนเห็น feature เช่น ถ้า Acetone มี 48% ใน target แต่มีเพียง 16% ใน source แม้รูปแบบ feature ภายใน class จะไม่เปลี่ยน โมเดลที่ยึด prior จาก source ก็อาจให้ probability ที่ไม่ calibrated บน target

Total Variation Distance (TVD) อยู่ระหว่าง 0–1; 0 หมายถึงสัดส่วน class เหมือนกันทุก class ค่า TVD ยังตีความได้ว่าเป็นมวล probability ขั้นต่ำที่ต้องย้ายระหว่าง class เพื่อให้สอง distribution ตรงกัน ส่วน Jensen–Shannon divergence เป็นอีกตัววัดที่สมมาตรและรองรับ class ที่มี probability เป็นศูนย์

ผลที่พบ: Batch 8 ต่างจาก Batch 1 มากที่สุด โดย TVD=0.3739 กล่าวได้ว่าต้องโยก probability mass อย่างน้อยประมาณ 37.4% จึงจะทำให้ prior ตรงกัน การเปลี่ยนที่เด่นที่สุดคือ C5 (Acetone) จาก 15.7% ใน source เป็น 48.6% ใน target หรือเปลี่ยน +32.9 percentage points ขณะที่ Batch 10 ใกล้ source ที่สุดในชุดเปรียบเทียบ (TVD=0.1090)
การนำไปใช้: หาก deployment มี prior แบบ Batch 8 ควรพิจารณา class weighting, prior-probability correction หรือ threshold calibration แต่ห้ามใช้ target test labels เพื่อเลือกวิธี/พารามิเตอร์แล้วรายงานผลบน test ชุดเดิม เพราะจะกลายเป็น test leakage

4. Global drift

MMD และ mean shift บอกอะไร

RBF-MMD² เปรียบเทียบ distribution ของ feature ทั้ง 128 มิติ ค่าใกล้ 0 หมายถึงสอง sample distributions คล้ายกันภายใต้ kernel ที่กำหนด และค่าที่มากขึ้นหมายถึงต่างกันมากขึ้น ไม่มีเกณฑ์สากลว่าเท่าไรจึง “สูง” จึงควรเปรียบเทียบแบบสัมพัทธ์ภายในรายงานที่ใช้ scaler, gamma และ sampling protocol เดียวกัน

Standardized mean-shift L2 ดูระยะห่างระหว่างค่าเฉลี่ยหลัง standardize ส่วน MMD มองความต่างของ distribution กว้างกว่า จึงอาจจัดอันดับ batch ไม่เหมือนกัน

ผลที่พบ: MMD สูงสุดคือ Batch 1 → Batch 5 ที่ 0.4874 แสดงว่า target นี้ต่างจาก source มากที่สุดภายใต้ RBF kernel ที่ใช้ แต่ mean shift สูงสุดเกิดที่ Batch 4 (27.94) ความต่างของอันดับสอง metric บ่งชี้ว่า drift ไม่ได้เป็นเพียงการเลื่อนค่าเฉลี่ย แต่อาจรวมการเปลี่ยน variance หรือรูปร่าง distribution ด้วย
ข้อจำกัด: ใช้ source-only scaling, RBF gamma=0.0029796342 และสุ่มไม่เกิน 400 ตัวอย่างต่อ domain ด้วย seed คงที่ ค่าเป็น biased MMD² เพื่อให้ไม่ติดลบ แต่ยังไม่มี p-value การที่ Batch 10 มี MMD ต่ำกว่า Batch 4–5 ไม่ได้พิสูจน์ว่า drift ลดลงตามเวลา เพราะ global MMD ยังได้รับอิทธิพลจาก class mix และ sample size

5. Class-wise drift

ทำไมต้องดูภายใน class

Global drift อาจสูงเพียงเพราะสัดส่วน class เปลี่ยน การเปรียบเทียบ source-target เฉพาะ sample ที่เป็น class เดียวกันช่วยลดผลของ prior mismatch หาก class-wise MMD ยังสูง แสดงว่า feature distribution ของก๊าซชนิดเดียวกันเปลี่ยนข้าม batch ซึ่งสอดคล้องกับ sensor/domain drift มากกว่าการเปลี่ยนสัดส่วน class อย่างเดียว

คู่ที่มี class-wise MMD สูงสุด 3 อันดับ:
  1. Batch 1 → Batch 5, C1 (Ethanol): MMD²=1.0246, n_source=90, n_target=28
  2. Batch 1 → Batch 4, C5 (Acetone): MMD²=0.9685, n_source=70, n_target=12
  3. Batch 1 → Batch 5, C4 (Acetaldehyde): MMD²=0.9140, n_source=30, n_target=46
ค่าอันดับหนึ่งคือ Batch 1 → Batch 5, C1 (Ethanol) ที่ MMD²=1.0246 จึงมีหลักฐานว่า feature ของ class นี้เปลี่ยนชัด ไม่ใช่แค่จำนวน class เปลี่ยน
ข้อควรระวัง: C6 ใน Batch 3–5 เป็น missing จึงคำนวณ class-conditional MMD ไม่ได้ และคู่ที่มี sample น้อย เช่น target บาง class มีเพียง 12–30 ตัวอย่าง อาจทำให้ค่าประมาณผันผวน ควรเพิ่ม bootstrap confidence interval หรือ permutation test หากต้องการข้อสรุปเชิงสถิติ

9. ข้อสรุปและแนวทางทดลองต่อ

หลักฐานที่พบความหมายสิ่งที่ควรทำต่อ
Class prior เปลี่ยนตาม batchโมเดลอาจ bias ไปยังสัดส่วนของ source และ probability อาจไม่ calibratedรายงาน macro-F1/balanced accuracy และทดลอง weighting หรือ prior correction
Global MMD ต่างกันชัดระหว่าง batchfeature distribution เปลี่ยน ทำให้ decision boundary จาก source อาจเสื่อมสร้าง baseline source-only แล้วเปรียบเทียบ domain adaptation/drift compensation
Class-wise MMD ยังสูงdrift ไม่ได้เกิดจาก class mix อย่างเดียว แต่เกิดภายใน class เดียวกันด้วยดู per-class recall และทดลอง class-conditional alignment
C6 หายใน Batch 3–5เกิด class coverage gap และวัด recall ของ C6 ใน batch เหล่านี้ไม่ได้แยกรายงาน “not observable” ออกจาก recall=0 และเลือก test batch ที่มีทุก class เมื่อจำเป็น
บาง batch imbalance รุนแรงAccuracy รวมอาจทำให้เข้าใจผิดใช้ stratified source validation เท่าที่ทำได้ และรายงานผลแยก class
Leakage audit ผ่านpipeline วิเคราะห์ปัจจุบันแยก fit scope ถูกต้องคงกฎ source-only preprocessing และล็อก test ก่อนเริ่ม tune โมเดล
บทสรุป: Dataset นี้ไม่ใช่เพียงปัญหา class imbalance และไม่ใช่เพียงปัญหา sensor drift อย่างใดอย่างหนึ่ง แต่มีทั้ง prior shift, missing-class coverage และ class-conditional feature drift พร้อมกัน การประเมินที่น่าเชื่อถือจึงควร split ตามเวลา/batch, หลีกเลี่ยง target leakage, ใช้ metric ที่คำนึงถึง class และรายงานความแปรปรวนข้าม seeds
